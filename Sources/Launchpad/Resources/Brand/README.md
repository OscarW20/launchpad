# Launchpad brand

- `Logo.svg`: the master logo (vector).
- `AppIcon-1024.png`: macOS app icon on Apple's grid (824 px rounded square, 100 px margin, soft shadow), made from the glossy artwork.
- `AppIcon.iconset/`: every macOS size; `scripts/make-app.sh` turns it into `AppIcon.icns`.
- `AppIcon-iOS-1024.png`: iPhone icon (square, opaque; iOS rounds the corners).
- `MenuBarIcon.svg` / `.png` / `@2x.png`: one-colour template icon for the menu bar (18 pt).
