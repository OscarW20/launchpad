# Logos

Brand marks for the marketplace's Apps tab. File names match `ConnectorPreset.logo` in
`Sources/LaunchpadCore/ConnectorCatalog.swift`; some files (e.g. claude, openai, ollama, gmail) are
not used by a preset yet and are kept for engine and settings screens.

- `*.svg`: from [Simple Icons](https://simpleicons.org) (CC0 1.0, public domain dedication).
- `*.png`: the vendor's own app or site icon, used where Simple Icons has no mark.

Simple Icons' CC0 covers the drawings only. Every logo is a trademark of its owner and is used here
only to identify that service; check each brand's guidelines before using a mark elsewhere.
